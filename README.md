## 🔭 Featured projects

**[QuantRanker](https://github.com/Ajitesh1234/QuantRanker)**: Cross-sectional stock ranking with
LightGBM LambdaRank, purged and embargoed walk-forward CV, and turnover-based transaction costs.

**[Predictor](https://github.com/Ajitesh1234/Predictor)**: Equity ranking model with beta-hedged

isn't loading (DNS, server, ISP blocking, or slow connection).
